You can close the browser while the game host continues downloading. Closing the host pauses the download; it resumes when you reopen the game. Existing games stay open while new artwork is prepared.

Keeping your artwork library

The first download is about 1.7 GiB, separate from the application ZIP. Keep the library in the Saved on host folder shown above: new installations reuse it automatically. Only the host needs the full library, including for LAN and Cloudflare games.

Updating the game and artwork

Extract each application update into a new folder. Leave your artwork library in place; the new build checks it and downloads only missing or changed packs. Return here using Card artwork on the main menu to check progress.

Artwork and game progress are stored separately. Copy your saves, replays, custom decks and campaign_settings.json from the old installation when updating. Copy any personal artwork overrides you want to keep, too.

Interrupted downloads or missing images

Use Resume after pausing. If a download fails, check the error above, restore the internet connection or free the required space, then choose Retry failed downloads. Keep completed artwork; you do not need to clear the library.

Restarting the host checks the stored artwork and prepares any missing or damaged files again. If an image looks wrong, check for a personal override in assets/pics or your configured image_folders; those take priority over managed artwork.

Moving or backing up the library

Close all running copies of the host before copying the entire artwork folder. To use a different location, set "artwork_folder": "D:/MarvelArtwork" in launch.json in every installation that should share it. An empty value uses the default user location.

Keep the library's files and subfolders together. Do not rename or edit its managed image files. Use assets/pics for personal replacements; cache_folder is a separate legacy setting. Deleting the managed library means downloading it again.
