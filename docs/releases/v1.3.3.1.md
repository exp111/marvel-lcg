# Marvel Champions Digital v1.3.3.1

This hotfix introduces a **persistent local card artwork library**, making card images reliable and readily available during games, deck building and browsing.

## Antivirus notice

The [VirusTotal report for the packaged executable](https://www.virustotal.com/gui/file/8277bb66d2a228c6c6c10f23e599184889e04a5a5be044944c8b63de7788794e?nocache=1) shows **2 of 70 security vendors reporting detections** as of October 11, 2026: **Microsoft** (`Trojan:Win32/Wacatac.C!ml`) and **SecureAge** (`Malicious`). The same executable passed an earlier local Microsoft Defender scan, but these differing results remain an **unresolved antivirus warning**. Review the report and scan the downloaded package before running it.

**The application automatically downloads card images from the hosted artwork packs and saves them locally on the host computer.** The changed artwork download and storage behavior may be a factor in the detections, but the cause has not been confirmed; they should not be assumed to be false positives.

## Card artwork stored locally

On first launch, the application automatically downloads the complete supported artwork collection to the host's local library before first play, with clear progress and Pause, Resume and Retry controls. Interrupted downloads resume when the host restarts.

The **application ZIP is about 40 MB**. The approximately **1.7 GiB artwork collection downloads separately** and stays on your computer across application updates. Existing verified artwork is reused, and later updates download only missing or changed packs.

Prepared artwork works offline. LAN and Cloudflare players receive images from the host, so only the host needs the full library. The Card Artwork screen now includes instructions for keeping, moving, backing up and recovering the library.

## Other improvements

- **Flexible encounter setup:** Other → Remove Standard Set Restriction is off by default. Enable it to select or deselect any combination of packs in the Standard Sets row, including multiple Standard or Expert variants.
- **Response confirmation:** With Auto Target enabled, a sole eligible response or interrupt in an existing prompt is preselected but still requires OK. Optional effects can still be passed. Forced effects that already resolve without a prompt keep their normal behavior.
- **Clearer artwork support:** Jessica Jones and Luke Cage cards that have not been implemented remain unsupported for both artwork and gameplay.

## Updating and keeping your files

1. Extract the ZIP into a **new folder**, keeping `marvel-lcg.exe` beside `_internal`. Copy and overwrite `campaign_settings.json` from the previous installation to retain campaign setup choices. Also copy personal saves, replays, custom decks and artwork overrides you want to keep.
2. Leave the artwork library in place. On Windows, its default location is `%LOCALAPPDATA%\Marvel Champions Digital\artwork`. If you configured `artwork_folder` in `launch.json`, use that same location in the new installation.
3. Open **Card Artwork** from the main menu to check preparation or retry failed downloads. Completed artwork is retained; there is no need to clear the library when updating.
